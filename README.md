# Data Structures & Algorithms

A collection of my **Data Structures & Algorithms** problem solutions from competitive programming and coding platforms.

This repository serves as a record of my problem-solving journey, with a focus on understanding the **ideas, patterns, and techniques** used to solve problems.

## What You'll Find

Each problem is organized separately and includes:

- **Problem Statement** — what the problem asks
- **Approach** — the reasoning and idea behind the solution
- **Complexity** — time and space complexity
- **Solution** — the final implementation

Typical structure:

```text
Problem-Name/
├── README.md
└── solution.cpp
```

The individual `README.md` files are meant to explain the solution, not just document the final code. When a problem involves an interesting observation, derivation, recurrence, or optimization, it is included there as well.

## Platforms

Solutions are collected from platforms such as:

- **Codeforces**
- **LeetCode**
- **AtCoder**
- Other online judges

## Language

Solutions are primarily written in **C++17** and **Rust**.

## Goal

The goal of this repository is simple:

> **Solve problems, understand the underlying patterns, and develop the ability to derive solutions independently.**

This repository will continue to grow as I solve more problems and encounter new techniques.
