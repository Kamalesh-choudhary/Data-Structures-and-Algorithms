## What is this?
This repository contains my solutions to Data Structures & Algorithms problems, solved as part of my interview preparation and practice. Previously synced from NeetCode, this is now maintained manually as I add new problems and revisit old ones.
---
## Repository structure
Solutions are organized by topic folder, then problem name. Each solution is stored as a separate file:
```
<topic-folder>/
  <problem-name>/
    solution.<ext>
```
**Example:**
```
Arrays & Hashing/two-integer-sum/solution.py
Binary Search/binary-search/solution.py
Two Pointers/valid-palindrome/solution.py
```
