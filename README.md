# Data Structures & Algorithms — @Kamalesh-choudhary
> My personal collection of DSA and coding problem solutions.
---
## What is this?
This repository contains my solutions to Data Structures & Algorithms problems, solved as part of my interview preparation and practice. Previously synced from NeetCode, this is now maintained manually as I add new problems and revisit old ones.
 
I use this repo as both a practice log and a personal reference — a place to look back at how I approached a problem earlier, and to track how my solutions get cleaner and more efficient over time.
---
## Why I maintain this
- Build strong, lasting fundamentals in data structures and algorithms rather than cramming before interviews
- Keep a searchable history of problems I've solved, so I can revisit patterns instead of re-learning them from scratch
- Practice writing clean, efficient code — not just code that passes
- Track my own growth by comparing older solutions to newer, better ones on the same problem
---
## Repository structure
Solutions are organized by topic folder, then problem name. Each solution is stored as a separate file:
```
<topic-folder>/
  <problem-name>/
    solution.<ext>
```
**Example:**
```
Arrays & Hashing/two-integer-sum/solution.cpp
Binary Search/binary-search/solution.cpp
Two Pointers/valid-palindrome/solution.cpp
```
If I come back and solve a problem again with a better approach, I add it as a new file (`solution-2.cpp`, etc.) rather than overwriting the old one — so the history of how I got better stays intact.
---
## How I approach a problem
1. Read the problem and work out a brute-force solution first, even if it's not optimal
2. Think through time and space complexity before optimizing
3. Look for patterns — sliding window, two pointers, recursion, DP, etc.
4. Write a clean, working solution and test it against edge cases
5. Revisit tricky problems after a few days to see if I can solve them faster or more elegantly the second time
